# 界面交互偏好

功能与设置含义见[软件设计指引](software-design-preferences.md)，实现与真实操作验证见[macOS 验证流程](macos-validation.md)。本文只保留影响界面决策的偏好。

## 窗口打开与返回

- 纯状态栏菜单／popover 可无 Dock 图标；设置等独立业务窗口打开后保留应用 Dock 入口，失焦、隐藏或最小化后仍可返回。最后一个独立窗口关闭后可恢复纯状态栏行为，关闭窗口与退出应用分开。
- 临时快捷面板、输入法候选窗和截图浮层沿用各自的焦点与返回方式。
- 首开、切页和重开时，普通组件不因自动聚焦出现蓝框；明确的“打开即输入”需求保留。用户主动键盘导航时显示清楚的焦点提示。

## 键盘与工具操作

主动接入 [macOS 标准快捷键](https://support.apple.com/en-us/102650)，菜单与按键使用同一入口：

- `Command + ,` 打开或激活同一个设置窗口；`W / Q / H / M` 分别关闭、退出、隐藏、最小化，保留常驻行为和未保存内容处理。
- `Command + C / X / V / A` 与 `Z / Shift + Z` 支持标准编辑及撤销／重做；`F`、`N / O / S`、`T` 随实际查找、文档和标签页能力接入。
- 命令作用于当前焦点或选中对象，自定义快捷键避开文本编辑、输入法和系统切换。

高频选择面板支持连续键盘操作，选中项自动滚动可见。Enter、Esc、Tab 沿用确认、取消和切换语义；Space 保留已有预览或文本空格用途，其余非文本选择可用于确认。

可配置的快捷键应实际可改，并与菜单、提示一致；固定绑定作为说明。新增截图入口未定默认值时采用 `Command + Shift + A`，保留用户自定义。工具提示使用“名称＋快捷键”，选中态、光标和可用选项随工具同步。

## 设置页面

采用**现代简洁风格**，参考 [Raycast 设置](https://manual.raycast.com/settings) 的侧栏与内容组织：

- 有分类时，左侧紧凑文字导航可配小图标，右侧显示标题与分组内容；少量设置使用同风格单页。
- 以克制的背景差异区分分组，标签、说明与控件对齐，内容宽度和留白与信息量相称。
- 禁止传统“大图标＋文字顶部分类工具栏”的偏好窗口风格。

复用设置窗口和配置来源，状态栏菜单也提供入口；重开恢复最近分类。初始尺寸容纳常用内容，切页保持稳定，长内容在页内滚动。分类按实际功能命名，“通用”放跨功能偏好；查找困难时再提供搜索。

### 通用设置项

| 项目 | 呈现 |
|---|---|
| 语言 | 选择控件，包含跟随系统和实际支持的语言，语言使用自身名称 |
| 外观 | 选择控件，包含跟随系统、浅色、深色；需同时展示选项且空间足够时使用分段控件 |
| 版本 | 同页信息区或已有关于区域中的只读标签和值，读取应用元数据 |

语言与外观同组；仅有这三项时使用单页。这里不放反馈入口。默认值与生效语义见[通用设置约定](software-design-preferences.md#通用设置项)。

### 编辑与反馈

- 从属选项靠近控制项，说明紧邻对应设置；条件不满足时就地解释或提供处理入口。
- 可直接生效的选择即时应用，文本按失焦或 Enter 保存；需整体校验时提供保存／应用。耗时操作保持页面可操作，就地反馈结果或重启要求。
- 恢复默认明确作用范围；清除数据等破坏性操作说明影响并要求确认，恢复偏好保留用户内容。

复用当前技术栈的原生控件，保留明暗与本地化适配；在真实窗口中检查密度、层级和长文本布局。

## 跨屏与后台行为

- 跨屏后的第一次快捷键、截图或浮层操作直接作用于当前目标；浮层跟随对象或触发位置。
- 后台观察和同步保持安静，不抢焦点、移动鼠标、打开设置或打断输入。
