# `plan-feature-execution` 技能组研究

> 中文名称：功能实施规划<br>
> 当前阶段：Echo 技能已完成近期真实使用复盘，并实施决策前置、阻断权收敛和工具包增量审核优化<br>
> 创建日期：2026-08-13

## 研究目标

研究一套由实施规划和独立审核组成的可复用技能组：当功能需求已经确定时，结合当前代码、工程约束和交付条件，将需求转换为可审核的实施方案、可独立分享的开发工具包以及可交给新会话直接执行的任务单。

## 当前技能源码

技能源码已统一迁入仓库根目录的 [`skills/`](../../skills/)；本目录只保留研究、决策和验证记录：

| 技能 | 目录 | 职责与触发方式 |
|---|---|---|
| `echo-planpack` | [`../../skills/echo-planpack/`](../../skills/echo-planpack/) | 当功能需求已经确定、需要转为具体实施方案与开发工具包时使用；可根据描述触发 |
| `echo-planpack-review` | [`../../skills/echo-planpack-review/`](../../skills/echo-planpack-review/) | 正式独立审核方案或开发工具包并创建外部审核记录；只允许显式触发 |

根目录 `skills/` 是可继续修改的唯一事实源。本文件关于历史安装结果的时间线仅代表当时验证，不代表当前设备安装状态。开发工具包的实际执行不依赖这两个技能，普通新会话只需取得工具包路径即可开始工作。

## 安装与更新

回到仓库根目录，使用统一资源管理器：

```bash
make validate
make status
make install
```

默认把仓库中的全部稳定 Skill 以符号链接安装到 `~/.agents/skills`。如果存在同名资源，管理器默认停止；确认接管时运行：

```bash
python3 scripts/manage.py install --force
```

管理器会先把冲突项移动到可恢复备份，再执行安装。原 `install-skills.sh` 仅作为历史实现快照保留，已禁用执行，不再是发布入口。

| 2026-08-14 | 优化审核循环 | 保留原有产物和确认流程，改为同一对象复用独立审核会话、当前文档完整检查与事实增量复核，并增加送审范围、事实索引和送审准备检查 |
| 2026-08-19 | 复盘六个近期规划包 | 确认审核耗时下降但方案扩散和人工改向仍存在，根因转向高影响决策确认过晚、阻断权过宽和工具包重复事实调查 |
| 2026-08-19 | 收敛通用技能流程 | 增加条件式实施决策对齐；允许真实独立交付流；收紧阻断资格；工具包默认复用方案审核者并只审核方案到任务的转换 |

## 后续待研究

- 使用后续真实样本继续验证实施方案和详细任务单的最小必需字段。
- 任务单静态校验脚本的输入格式和检查边界。
- 使用真实功能样本继续校准方案与任务模板的最小字段和拆分粒度。
- 决定首版技能的安装/分发方式，并验证安装后的显式与隐式触发行为。
- 根据至少两个新的同等复杂度样本，对比高影响决策命中、审核后人工实质修改、阻断依据质量、工具包代码重读范围和各阶段耗时。
