# 独立审核交接模板

只向审核者提供完成审核所需的最小充分上下文。规划者的自检发现和已知风险可以作为“待独立核验线索”提供；不得附带预计审核结果、通过压力或指定修复方案。独立性要求审核者独立判断，不要求对已知线索保持无知。

## 1. 自动委托子代理

```text
请使用 $echo-planpack-review 执行正式独立审核。

技能位置：<echo-planpack-review/SKILL.md 的可访问路径>
审核类型：<方案审核 | 开发工具包审核>
审核轮次：<初审 | 复审>
审核者身份约束：<方案初审使用新隔离审核者；方案复审和工具包审核默认复用方案首次审核者；只有审核者不可继续、独立性受损、上下文丢失、用户要求新审核者或工具包引入方案未覆盖的高风险事实时才更换，并记录原因>
被审核对象：<路径>
声明版本：<方案版本；工具包则写当前副本>
送审开始摘要：<SHA-256；审核者仍须独立重算>

规范性来源：
- <路径、具体适用章节/条目及其规范作用>

兼容约束：
- <路径、具体适用章节/条目、必须保持的契约；没有则写不适用>

允许核验的事实性来源：
- <仓库或资料路径及允许范围>

送审范围：
- 直接受影响行为链：<枚举>
- 保持不变行为：<具体对象、事实编号和验收方式>
- 范围外：<枚举>
- 允许扩展条件：只有发现与本期变更存在可举证的直接依赖，才能扩大阻断范围

关键事实索引：
- <事实编号：行为；仓库相对路径/符号；核验方式；内容摘要或指纹；所支撑的设计/验收>

明确排除的来源：
- 预期审核结论、通过压力和指定修复方案
- <其他排除项>

待独立核验线索（可选）：
- <规划者自检发现或已知风险；只作为检索线索，不预设真伪、严重性或处置>

复审附加输入：
- 上一轮审核记录：<路径或“不适用”>
- 用户修改意见：<路径/原始明确意见或“不适用”>
- 本版变化说明：<变更章节、契约和验收；初审写不适用>
- 受影响事实编号：<编号列表或不适用>
- 完整事实调查触发情况：<未命中，或命中条件和需重新调查的范围>

工具包审核附加边界：<方案审核写不适用；工具包审核写明默认只检查方案到任务/依赖/权限/验收的转换，以及哪些新增事实或高风险变化需要重新核验代码>

审核记录输出目录：<方案审核记录/ 或 开发工具包审核记录/>
写入边界：只允许在上述目录新建一份审核记录；不得修改被审核对象或其他文件。
阻断权限：只有违反明确规范性来源/已确认方案、与直接工程事实矛盾、存在未控制的安全或数据风险、或导致实现/验收不可判定时才能阻断。新增治理要求、实现偏好和范围扩展候选不得阻断；必需修正只描述最小必须结果，不强制指定实现结构。
通过条件：没有符合上述资格的未解决阻断问题，且审核开始与结束摘要一致。

完成后仅返回：审核记录路径、开始/结束摘要、二元结论、各类发现数量和下一步。
```

方案初审建立独立审核会话；后续方案复审和工具包审核默认复用该会话。工具包是新的审核对象，但不是重建事实基线的自动理由。只有审核者不可继续、独立性受损、上下文丢失、用户明确要求新审核者，或工具包引入方案未覆盖的高风险事实时才重新创建，并在交接中写明原因和需要重建的事实范围。

## 2. 无合格子代理时给用户的复制提示词

```text
请在一个不带原规划会话历史的新会话中执行以下任务：

使用 $echo-planpack-review 正式独立审核下面的对象。先读取该技能的 SKILL.md 和它要求的参考文件。规划者已知线索只能作为待核验输入，不得据此预设结论或修复。

技能位置：<echo-planpack-review/SKILL.md 的可访问路径>
审核类型：<方案审核 | 开发工具包审核>
审核轮次：<初审 | 复审>
审核者身份约束：<方案初审使用新隔离会话；方案复审和工具包审核默认回到方案首次审核会话；只有明确原因成立时才更换>
被审核对象：<路径>
声明版本：<版本>
送审摘要：<SHA-256>
规范性来源：
- <路径、具体适用章节/条目及作用>
兼容约束：
- <路径、具体适用章节/条目及契约，或不适用>
允许核验的事实性来源：
- <路径及范围>
送审范围：
- <直接受影响行为、保持不变行为、范围外和允许扩展条件>
关键事实索引：
- <事实编号、定位、核验方式和内容指纹>
明确排除的来源：
- <排除项>
待独立核验线索：
- <可选；没有则写不适用>
上一轮审核记录：<路径或不适用>
用户修改意见：<路径/原始明确意见或不适用>
本版变化说明：<复审填写；初审写不适用>
受影响事实编号：<编号或不适用>
完整事实调查触发情况：<未命中，或命中条件和范围>
工具包审核附加边界：<转换审核范围及需要重核的事实；方案审核写不适用>
审核记录输出目录：<路径>

阻断只允许基于明确规范/确认方案、直接事实矛盾、未控制的安全或数据风险、或实现/验收不可判定。新增治理要求、实现偏好和范围扩展候选不得作为阻断；必需修正只描述最小必须结果。

只允许在审核记录输出目录新建一份审核记录，不得修改方案、开发工具包、代码或其他文件。审核完成后返回记录路径、开始/结束摘要、二元结论和发现数量。
```

默认直接在对话中返回该提示词，不把它保存到功能规划目录。只有用户明确要求留档时才创建过程文件，并明确标识它不是正式方案、工具包或审核记录。发送该提示词后，规划流程停在“待独立审核”；只有新会话产生有效审核记录，原流程才能继续。
