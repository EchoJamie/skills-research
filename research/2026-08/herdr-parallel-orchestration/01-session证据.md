## 5. 可确认结果与证据限制

可确认：

- Herdr 提供了用户可见的长期 Agent 会话、稳定命名、分组和直接读取能力。
- 以任务结果、文件所有权和后继工作组织 Pane，比“保留若干空闲小弟”更有效。
- 用户多次纠正主智能体等待、慢推进或只顾调度的倾向；触发并行不意味着主智能体停止原有工作。
- 主智能体亲自处理全局前置、集成和验收时，能发现数据源漂移、错误语义和多库隔离问题。
- 读写验证重叠确实产生过一次中间态假失败；稳定后重跑消失。

不能确认：

- 不能从单一样本计算 Herdr 相比内置子代理的净性能提升。
- Session 包含多次用户改向、环境修复和业务 Gate，端到端耗时不能直接作为调度效率指标。
- 可见 Agent 与内置子代理共同修改同一工作树，最终成果不能做单一归因。
- 原 session 的成功并不证明新 Skill 已被 Codex 正确发现或运行。
