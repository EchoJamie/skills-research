# Herdr 可视化并行编排

在复杂实施、调研或验收任务中，让当前主智能体持续亲自推进目标，同时使用 Herdr 中用户可见的 Agent 加速独立责任。主智能体和 Herdr Agent 都是能够审查事实、规划步骤并完成工作的完整智能体；该 Skill 只保留会改变判断的非显然协作提醒，不替它们建立机械调度流程。

若决定使用多个智能体，默认采用 Herdr 可视化协作，不自行委派不可见的内置子代理。具体 Herdr 命令、安全约束和状态语义以当前环境中的 `herdr` Skill 与本机 CLI 为准。

## 判断与分工

1. 先判断任务是否真的存在可以同时推进的独立工作。单智能体足以高效完成时，当前主智能体直接做，不为形式启动 Herdr。
2. 决定使用多智能体时，完整读取并遵循当前可用的 `herdr` Skill，并按其要求确认 `HERDR_ENV=1`。环境不可用时，主智能体继续完成仍可完成的工作并报告限制，不静默改用内置子代理。
3. 只有用户明确要求，或适用的必需工作流指定了其他精确 Agent 机制时，才偏离 Herdr 默认。已有不可见任务让原负责人完成当前工作包，后续任务改走 Herdr；不打断、复制或迁移半成品。
4. 并行不扩大提交、部署、数据写入、外部操作或其他授权边界。

主智能体根据目标、当前事实、现有工作和授权边界自行审查怎样分工；这属于正常推理，不增加独立检查阶段。它始终保留并执行至少一项直接推进目标的具体责任，不能因派发而中断已经进行中的主线工作。

只把边界清楚、能够独立闭环的局部责任交给 Herdr Agent。调用常用的 `herdr agent prompt` 时，说明责任结果、所有权范围、关键事实与权威来源，并允许负责人先自行核对事实、决定步骤，然后持续推进到责任闭环；不要把完整智能体降格为每做一步都等待续派的一次性执行器，也不要替它预制不必要的任务队列和检查清单。

一个紧密耦合的责任只设一个负责人。Agent 名称应持续反映其真实责任；做到一半不换人，偏离时只纠正错误事实、目标或边界。完成原责任后若转入不同领域，应同步调整可见责任，而不是让旧名称掩盖新工作。

下列全局影响工作由当前主智能体择机亲自执行，不作为普通 Agent 工作包派发：

- 共享契约、迁移、公共配置和跨工作包重构或删除；
- 会影响其他任务的服务、环境、性能负载和全量验证；
- 全局 Diff、集成取舍、目标级决策以及 Git、交付和数据变更。

Agent 可以收集范围明确的局部事实，但全局动作的时机、执行和结论仍由主智能体负责。命令可以放在可见命令 Pane 中运行，发起者和责任人仍是主智能体。

## 关键提醒

- 派发后立即继续主智能体自己的主线，不进入固定的状态检查循环。Herdr 不会把邻居 Agent 的完成或阻塞主动注入当前会话；只在主智能体自身的自然检查点、下一步真实依赖或用户询问时读取必要状态，只有确实无事可做时才等待。
- 分给 Agent 的责任必须直接推进当前目标。不要为了让 Pane 看起来繁忙而制造旁支调研、重复产物或额外检查；没有真实责任时就不扩容或释放负责人。
- 多智能体发生冲突时，优先判断责任划分、所有权或先后依赖是否错误，重新分工后让原负责人继续；不要用更频繁的扫描、轮询、锁或事后重跑掩盖分配问题。
- Agent 间需要衔接时，让下游直接读取上游 Agent 的原始结论或稳定产物，主智能体不充当逐条转述中继。
- 用户目标、公共契约或全局事实变化时，由主智能体及时通知受影响负责人。负责人基于新事实重新审查责任路径；仍然有效的工作保持原负责人，不能继续沿用已经失效的前提。

局部负责人完成与其责任相称的局部验证；主智能体只在自然集成点执行必要的全局验证，不机械重复每个 Agent 已完成的检查。若一项工作无法在不增加复杂协调的情况下独立闭环，就留给主智能体或并回它所依赖的责任。

## 可见工作面

按责任或生命周期组织 Tab，使用稳定、可辨识的 Agent 名称。只在现有工作面难以阅读或新工作具有独立生命周期时新增 Tab；不以占满 Pane 为目标。

启动和控制细节遵循 `herdr` Skill，不在此复制命令、审批、沙箱或状态判断规则。

## 用户可见性

建立或调整工作面后，向用户简要报告主智能体正在亲自推进的工作、Herdr Agent 的局部所有权和交接出口。之后只在真实里程碑、需要用户决策或授权的阻塞、运行验证结论、用户询问或拓扑变化时更新。

报告必须区分：Agent 自报、主智能体静态复核、自动化测试、真实服务或环境验证。用户要求每次性能测试后报告时，测试一结束就单独报告，不能用预检或普通单测替代。

## 完成与清理

主智能体在合适时机整合结果、执行与风险相称的全局验证并给出最终结论。只清理本轮创建且不再承担责任的资源，不关闭用户或其他客户端创建的工作面。

最终交接区分 Agent 自报、主智能体静态复核、自动化测试和真实环境验证，并列出未验证项。Herdr 生命周期状态不等于任务正确完成。
