# Herdr 并行编排 Skill 研究

本目录按研究和改良发生的时间保存记录。已经形成的阶段文档保持当时的事实、判断和版本边界；后续运行暴露的新问题与整改结果追加新文档，不回填改写早期结论。

## 研究边界

- 主要事实源是本机 Codex rollout JSONL，不以回忆或最终总结替代原始事件。
- 重点分析 Herdr 的 Tab、Pane、Agent、派发、等待、直接交接、扩缩容和收口行为；Dolphin 业务只作为调度上下文。
- Session 同时使用过 Herdr 可见 Agent 和 Codex 内置子代理时，不把全部产出归因于 Herdr。
- 研究记录不复制凭据、业务正文、查询文本、完整 URL 或原始会话输出。
- 对仍在运行的 session 只记录读取时已经出现的事实；到达当时文件末尾后形成阶段结论，不把文件末尾当成会话终态。
