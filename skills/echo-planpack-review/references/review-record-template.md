# 审核记录模板

审核记录由审核者创建。文件名使用 `YYYYMMDD-NN-方案初审.md`、`YYYYMMDD-NN-方案复审.md`、`YYYYMMDD-NN-开发工具包初审.md` 或 `YYYYMMDD-NN-开发工具包复审.md`。

方案初审使用完整记录。方案复审和同一审核会话中的工具包增量审核可以引用上一轮稳定记录：保留对象摘要、实际变化、复核范围、旧问题闭环、新发现和结论，不重复抄录未变化的来源、事实和边界表。工具包首次审核仍须完整说明方案到任务的转换范围，但已复用的方案事实只列编号和依据。

> 审核类型：方案审核 / 开发工具包审核

## 编号规则

- 方案发现使用 `方案-阻断-01`、`方案-风险-01`、`方案-建议-01`。
- 工具包发现使用 `工具包-阻断-01`、`工具包-风险-01`、`工具包-建议-01`。
- 同一份记录内连续编号；复审引用旧编号，但新问题使用新的本轮编号。

## 文件创建规则

1. 读取输出目录已有的 `YYYYMMDD-NN-*.md`。
2. 取当天最大 `NN` 加一；没有文件时从 `01` 开始。
3. 创建前再次检查目标文件不存在。
4. 若发生并发冲突，重新扫描并使用下一个编号。
5. 只创建一份记录，不覆盖旧记录，也不把记录写进开发工具包。
